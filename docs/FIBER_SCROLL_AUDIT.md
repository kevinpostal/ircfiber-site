# Fiber vs IRCCloud Scroll Audit — 2026-08-24

> Sources: `site/docs/IRCLOUD_SCROLL_CADENCE_DISASSEMBLY.md` (common-5650bddb.js offsets), `site/frontend/src/components/MessageList.svelte` (2377 lines), `site/frontend/src/lib/scroll.ts`, `site/frontend/src/lib/scrollAnchor.ts`, `site/frontend/src/components/LoadMore.svelte` (426 lines).
> Contract: BATCH_SIZE must stay 200, TRIM 350→200, `scrollTop===0` exact, 1px slop. No code edits in this audit. Copy requested at `/tmp/fiber_audit.md` mirrored here at `site/docs/FIBER_SCROLL_AUDIT.md` for allowed-dir tooling.

## Summary

Fiber achieves the headline cadence (batch 200, trim 350→200, `a-31 → max(a-152,48)` half-way, 200ms pacing) but surrounds the strict IRCCloud predicates with 7+ invented guards that change observable behavior under fast wheel/trackpad/keyboard and on ANSI-heavy channels. Each guard is listed below with line anchor, divergence classification, and recommendation.
